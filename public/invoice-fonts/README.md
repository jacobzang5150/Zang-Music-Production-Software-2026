Invoice fonts supplied by the project owner: Copperplate Bold (copperplate.otf) and Arian LT Demi (arian-lt-demi.ttf). The PDF exporter embeds these fonts directly; no simulated small caps or fallback substitutions are used for invoice exports.

The PDF-compatible copperplate-pdf.otf is generated by scripts/prepare-invoice-font.py (Python fontTools). It preserves the supplied vector outlines and Unicode mapping while expanding legacy accented composites and converting the CFF character set to CID form for portable PDF embedding. The original copperplate.otf is preserved as supplied. The derived display and PDF variants omit the detached dot above the lowercase small-cap i, as requested. HTML uses copperplate-display.otf.
